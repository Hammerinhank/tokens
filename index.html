Changer mes tokens

v1.4.0

1 · Tokens trouvés sur cet appareil

Analyse du stockage local de ce navigateur, pour ce domaine uniquement. Les entrées sont regroupées par token : une même valeur utilisée par plusieurs apps apparaît une seule fois.

2 · Sauvegarde avant modification

Enregistre la valeur actuelle de toutes les clés concernées. À faire avant l'étape 3 : c'est le seul moyen de revenir en arrière si quelque chose se passe mal.

3 · Nouveau token

Rappel : « Regenerate » sur GitHub invalide l'ancien token immédiatement. Garde cet écran ouvert et fais le remplacement dans la foulée.

4 · Diagnostic

Toutes les clés du stockage local, y compris celles où aucun token n'a été reconnu. Utile si une app garde son token sous une forme inhabituelle.

Régénérer un token sur GitHub

  1. Ouvre la liste correspondant à ton type de token (voir ci-dessous).
  2. Clique sur le nom du token à remplacer pour ouvrir sa fiche.
  3. Clique sur Regenerate token, choisis une durée de validité, confirme.
  4. Copie la nouvelle valeur : GitHub ne la réaffichera jamais.
  5. Reviens ici, colle-la, vérifie, puis remplace.
Tokens à portée fine préfixe github_pat_ — le cas le plus courant chez toi Tokens classiques préfixe ghp_
La régénération invalide l'ancien token immédiatement. Fais la sauvegarde de l'étape 2 avant, et enchaîne le remplacement sans attendre.
